# eellak/.github

Το αποθετήριο αυτό περιέχει τα κοινά αρχεία του οργανισμού ΕΕΛΛΑΚ στο GitHub. Το GitHub τα εμφανίζει αυτόματα σε κάθε αποθετήριο του `github.com/eellak` που δεν έχει δικά του.

This repository holds the shared community health files of the GFOSS organisation on GitHub. GitHub shows them automatically in every `github.com/eellak` repository that does not have its own.

| Αρχείο / File | Τι είναι / What it is |
|---|---|
| [`SECURITY.md`](SECURITY.md) | Πολιτική ασφάλειας και αναφοράς ευπαθειών / Security and vulnerability reporting policy |
| [`profile/README.md`](profile/README.md) | Η σελίδα του οργανισμού στο GitHub / The organisation's GitHub profile page |

## Έργα όπου η ΕΕΛΛΑΚ ενεργεί ως υποστηρικτής / Projects where GFOSS acts as steward

Στα παρακάτω έργα η ΕΕΛΛΑΚ ενεργεί ως υποστηρικτής λογισμικού ανοικτού κώδικα (open-source software steward) κατά τον Κανονισμό (ΕΕ) 2024/2847 (Cyber Resilience Act). Για αυτά ισχύει το [`SECURITY.md`](SECURITY.md) ως πολιτική κυβερνοασφάλειας του άρθρου 24.

For the projects below, GFOSS acts as an open-source software steward under Regulation (EU) 2024/2847 (Cyber Resilience Act). The [`SECURITY.md`](SECURITY.md) is their cybersecurity policy under Article 24.

The list is approved by the GFOSS Board of Directors and reviewed every year.

## Έργα που δεν υποστηρίζονται / Unsupported projects

Τα υπόλοιπα αποθετήρια του οργανισμού, δηλαδή forks έργων τρίτων, έργα Google Summer of Code, datasets, στατικοί ιστότοποι και αρχειοθετημένα αποθετήρια, δεν λαμβάνουν διαρκή υποστήριξη από την ΕΕΛΛΑΚ. Όταν ένα έργο παύει να υποστηρίζεται, το αρχειοθετούμε και το σημειώνουμε στο `README.md` του. Πριν από την αρχειοθέτηση ελέγχουμε το αποθετήριο για κωδικούς, κλειδιά και άλλα μυστικά.

All other repositories in the organisation, namely forks of third-party projects, Google Summer of Code projects, datasets, static websites and archived repositories, do not receive sustained support from GFOSS. When a project stops being supported, we archive it and note this in its `README.md`. Before archiving, we check the repository for passwords, keys and other secrets.
